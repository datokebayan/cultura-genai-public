# Evidence gates: prototype to real operations (aiming for TRL 9)

| Gate | Required independent evidence | Current state |
|---|---|---|
| Static demo | Github URL, functional modules, scenario quizzes, dummy role walkthrough | Implemented; requires browser acceptance testing |
| Pilot readiness | Institutional ethics/legal approval; child protection and consent; culturally appropriate content validated with speakers | Not done |
| Real deployment | Verified user identities, server-side permissions, secure DB, reviewer controls, rate limiting, audit records | Not implemented |
| Real GenAI coach | Server-only API key, protected endpoint, model output monitoring, privacy/safety review, fallback | Not implemented |
| Microcredential trust | Institutional issuer policy, assessment moderation, identity verification, Open Badges 3.0 if chosen, verifier/revocation | Not implemented |
| Learning efficacy | Pre/post or comparable authentic assessments, rubrics, qualitative feedback, sample justification, limitations | Not done in this platform |
| Accessibility | WCAG 2.2 evaluation, multilingual/native-speaker review, screen-reader and keyboard tests | Not externally audited |
| Operational resilience | Pen testing, backups/restores, incident response, uptime logs, on-call ownership and maintenance | Not done |
| TRL 9 | System used successfully in actual operating environment with documented sustained evidence | Not achieved |

## QS evidence plan
Academic rationale: m-DOAI D/O/A/I activity and human judgement, adapted CADG for cultural design. Document baseline, learning journey, source-checking rubrics, human-assessor decisions, authentic outcomes, stakeholder participation, consent and ethics, replicability and limitations. Never reuse synthetic demo metrics as learner results.

## ITEX evidence plan
Demonstrate program under multilingual conditions (no internet model required), learner quiz -> evidence -> assessor review -> demo badge. Document code originality, usability protocols, stakeholder roles, intellectual property clearance, trial feedback, possible commercial segment. Feature availability alone is not novelty or TRL proof.

## Suggested pilot structure
First approve institutional ethics/safeguarding for any learners. Test with a small group of adult educators first. Evaluate task completion, success in verifying AI outputs, cultural suitability, user feedback, accessibility and operational exceptions. Extend to students only after safeguarding, guardian consent when needed, and internal authorisation.
